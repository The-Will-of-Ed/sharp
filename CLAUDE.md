# Sharp agent instructions

Read `AGENTS.md` for project instructions. For a new user or environment, follow `docs/SETUP.md` to install the local environment, register Sharp's stdio MCP server, verify tool access, and create a private workspace.

For career import, read `skills/sharp-career-import/SKILL.md`; for resumes read `skills/sharp-resume-create/SKILL.md`; for cover letters read `skills/sharp-cover-letter/SKILL.md`. Use the current agent for reasoning and Sharp's MCP/CLI for validated operations. Preserve originals and user approvals. Do not edit core code to tailor a person's resume.
