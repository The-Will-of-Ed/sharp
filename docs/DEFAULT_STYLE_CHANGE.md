# User-approved default style change, October 20, 2026

The user replaced the former no-bold default with bold name, target-role,
section/employer headings and degree rows. Body/bullet text remains regular.
The palette is charcoal #1A1A1A, orange #C44B12 and blue #1F5A8A.
These values live in shipped semantic styles and remain user-editable.

Work/project list items have a configurable marker and hanging indentation.
The marker is presentation, not part of canonical career wording. PDF output
uses list structure L/LI/Lbl/LBody and preserves selectable text/reading order.
This is not a claim of PDF/UA compliance or compatibility with every ATS.
Selected phrase emphasis uses existing explicit TextRun ranges; AI does not
invent a phrase-bolding policy. Old saved settings remain unchanged.

The old regular-only assertions intentionally describe the previous requirement.
They are superseded by explicit tests for the approved hierarchy, and separate
tests continue to verify that a user can request entirely regular output.
