# Sharp contracts

Generated by scripts/build_docs.py from the runtime contracts. Types and optionality are available through `sharp contracts_describe` or MCP `contracts_describe`.

All offsets are Unicode code points. All geometry is in points from the top-left. JSON and YAML encode the same logical contracts. Unknown Sharp fields are rejected. Standard JSON Resume core fields use its pinned upstream schema.
