# Fictional senior software engineer

Morgan Ellis is an invented benchmark candidate: nine years, four employers,
31 work bullets, 14 side projects, 49 skills and four approved summary options.
Every employment and performance claim is fictional, including IBM employment.
Smaller employer names and the school are invented. Contact information uses
example.com. No real candidate's career data was imported.

`master.yaml` uses Sharp's JSON Resume core plus its `x_resume` extension.
Confidence is neutral (`unrated`); approval means accepted scenario wording,
not external verification. Each claim points to synthetic-fixture evidence.

The profile is deliberately imperfect. It has production backend/full-stack,
cloud, streaming and developer-tools work, with modest independent AI projects.
It has no professional ML training, hyperscale, Rust/C++ or kernel/graphics
experience. A selector must preserve those limits rather than inventing skills.

See `docs/REAL_JOBS_BENCHMARK.md` for the 30-job evaluation and timing protocol.
